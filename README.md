## 🎯 About This Repository

This repository records my hands-on DSA practice using Python. The goal is to understand **how a data structure works, why an approach is correct, and how to translate it into code**—not just to collect solutions.

I use Jupyter Notebooks to keep the code easy to read, run, and revisit while preparing for coding assessments and technical interviews.

## 🚀 Run the Notebooks

### Option 1 — Open on GitHub

Click any notebook in the [problem library](#-problem-library) to view its code and saved outputs in your browser.

### Option 2 — Run locally

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Lakhan07AU/-hackerrank_DSA-python-.git
   cd -hackerrank_DSA-python-
   ```

2. **Install Jupyter if needed:**

   ```bash
   python -m pip install notebook
   ```

3. **Start Jupyter Notebook:**

   ```bash
   jupyter notebook
   ```

4. Open a `.ipynb` file and run its cells.

<details>
<summary><strong>✅ My problem-solving checklist</strong></summary>

When working through a problem, I aim to:

- [ ] Understand the input, output, and constraints.
- [ ] Write down a straightforward approach first.
- [ ] Consider edge cases before coding.
- [ ] Test the solution with sample and custom inputs.
- [ ] Review the time and space complexity.
- [ ] Revisit the problem later without looking at the solution.

</details>
